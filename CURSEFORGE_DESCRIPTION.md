# Ancient Dragon — CurseForge copy

## English summary

A world-unique colossal dragon boss with a sacred mountain, aerial and ground combat, persistent
progression, and a harvestable corpse.

## English description

Ancient Dragon adds a complete, world-unique boss encounter to Minecraft Fabric.

Far from spawn, the Overworld seed selects one deep-ocean site for a vast sacred mountain. Reach it
through exploration or activate the reinforced deepslate frame in an Ancient City with an Echo
Shard. Every valid gateway leads to the same mountain and the same Ancient Dragon.

The dragon is not a normal mob spawn. It begins dormant, awakens when players approach, and fights
through mountain, storm, and solar phases. Combat moves between open-sky attacks and a dedicated
ground platform. The server controls three-dimensional flight, multipart hitboxes, threat targets,
wing stability, player scaling, attack selection, death, and persistent encounter state.

After the final battle, the dragon becomes a physical corpse. Eligible participants can harvest it
for Ancient Dragon materials and continue progression through chronicles, advancements, the
Sunheart Altar, equipment, tools, and weapons.

### Requirements

- Minecraft 26.1.2
- Fabric Loader 0.19.3+
- Java 25+
- Fabric API 0.154.2+26.1.2
- [BlendLib 1.0.0-alpha.1+26.1.2](https://www.curseforge.com/minecraft/mc-mods/blendlib)
  or a newer compatible release
- Required on both client and server

## 中文说明

Ancient Dragon 为 Minecraft Fabric 加入一场完整且全世界唯一的古龙 Boss 遭遇。

主世界种子会在远离出生点的深海中选择唯一地点生成巨型神山。玩家可以直接探索，也可以手持回响碎片，
激活远古城市中央的强化深板岩框架。所有有效入口都会通向同一座神山和同一只古龙，不会重复生成遭遇。

古龙不是普通刷怪。它最初沉睡，玩家接近后苏醒，并依次经历群山、风暴和太阳阶段。战斗会在开放天空与
专用地面平台之间切换。服务器负责三维飞行、动态多部位碰撞箱、仇恨目标、翼部稳定性、多人生命缩放、
攻击选择、死亡与完整持久化状态。

最终击败古龙后，它会成为真实存在的尸骸。合格参战者可以采集古龙材料，并继续解锁余烬档案、进度、
日轮心坛、装备、工具和武器。
